Faça **toda** a avaliação de banco descrita em [`N1.md`](N1.md) (Partes 0, 1 e 2).

## Parte B: Página da eleição (Front End)

Evolua a página **"Viver Bem · Eleição CIPA 2026"** feita em aula (HTML + CSS + JS puro) para que ela **leia os dados do seu banco no Supabase e cadastre novos eleitores**.

### Requisitos

1. **Apuração:** mostre a apuração lendo a view `vw_apuracao`.
2. **Candidaturas:** mostre os candidatos lendo `vw_candidatos_por_chapa`, como cards, aproveitando o layout da aula.
3. **Cadastro de eleitor:** crie um formulário com nome, CPF, idade e setor. A lista de setores vem da tabela `setor`. O formulário grava na tabela `eleitor` e mostra uma mensagem de sucesso ou de erro.
4. **Publicação:** publique a página em um endereço público (GitHub Pages, Vercel ou Netlify).
5. **Segurança:**
   - use somente a **URL do projeto** e a **chave `anon`/publishable** no JavaScript, **nunca** a senha do banco nem a chave `service_role`;
   - ative o **RLS** nas 5 tabelas;
   - crie políticas para que o público possa **ler** os dados e **inserir apenas em `eleitor`**.

Para acessar o Supabase, use a biblioteca `@supabase/supabase-js` pelo CDN ou a API REST com `fetch`.

### Contrato da página (obrigatório para a correção automática)

O corretor abre a página num navegador automático e procura estes atributos `data-testid`:

| Elemento | `data-testid` | Observação |
|---|---|---|
| Cada linha/cartão da apuração | `apuracao-linha` | Um por chapa |
| ↳ número da chapa (dentro da linha) | `numero-chapa` | Só o número, ex.: `20` |
| ↳ total de votos (dentro da linha) | `total-votos` | Só o número, ex.: `42` |
| Cada card de candidato | `candidato` | |
| ↳ nome do candidato (dentro do card) | `nome-candidato` | |
| O formulário de cadastro | `form-eleitor` | Precisa ter `<button type="submit">` |
| Mensagem de retorno | `mensagem` | |

Os campos do formulário precisam ter estes `name`: `nome_eleitor`, `cpf`, `idade` e `id_setor`. O campo `id_setor` é um `<select>` com o `value` igual ao `id_setor` do banco.

Exemplo mínimo de uma linha da apuração:

```html
<li data-testid="apuracao-linha">
  Chapa <span data-testid="numero-chapa">20</span>:
  <span data-testid="total-votos">42</span> votos
</li>
```

Os dados precisam ser carregados **do banco**: o corretor compara o que a página mostra com o conteúdo atual do seu banco.
